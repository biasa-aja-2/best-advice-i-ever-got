One sentence, under 200 characters, about the best advice the writer ever
received.

> My grandfather said, 'Never borrow money from a friend — the debt outlives the friendship,' and the one time I ignored him, he was right.

## Why this line

The advice comes from a real person, not a fortune cookie: a grandfather,
speaking plainly. The first half is the advice itself — concrete, the kind
you can carry for a lifetime. The second half is the proof it was earned:
the writer ignored it exactly once, and the advice turned out right. That
turn is what makes it a memory rather than a slogan, and it lands on the
last three words, "he was right", which is the whole story in miniature.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python stdlib, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
self-check gate (1–200 characters, single line, not whitespace-only) and a
byte-exact read-back verification.
